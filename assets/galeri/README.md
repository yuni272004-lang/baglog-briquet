# Dokumentasi Galeri EcoBriq

Simpan dokumentasi asli kegiatan KKN EcoBriq di folder ini.

Nama file yang digunakan untuk dokumentasi penjemuran baglog:
- `penjemuran-baglog.jpg` — foto penjemuran baglog jamur.
- `penjemuran-baglog.mp4` — video proses penjemuran baglog jamur.

Pastikan file foto dan video benar-benar disalin ke folder ini sebelum ditampilkan pada halaman Galeri. Jangan mengganti dokumentasi asli dengan foto ilustrasi.
